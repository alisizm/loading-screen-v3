## 🇬🇧 English Description

Alisizm Loading Screen V3 is designed to give your players the best possible entry experience. Packed with interactive tabs and a built-in media player, it allows server owners to showcase their community, rules, and latest updates in a highly polished interface.

### ✨ Key Features
*   **Modern UI:** Clean, modern, and fluid user interface design.
*   **Dynamic Backgrounds:** Support for both video and image slideshow backgrounds.
*   **Advanced Music Player:** Built-in player featuring a playlist, progress bar, volume control, and shuffle capabilities.
*   **Interactive Tabs:** Dedicated sections for Staff, Updates, Rules, Info, and a visually appealing Gallery.
*   **Easy Configuration:** Modify themes, texts, and settings effortlessly via `config.js`.
*   **Optimized Performance:** Fully FiveM compatible and built with a performance-focused structure.

### 🔒 Escrow Status & Customization
This resource is protected by the FiveM Asset Escrow system. However, it is built to be customizable. 
The `config.js` file and your custom media files are **fully unencrypted and editable**, allowing you to tailor the loading screen entirely to your server's brand.
